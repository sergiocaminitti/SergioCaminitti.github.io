# Portfólio de Sérgio Caminitti

Site pessoal publicado com GitHub Pages: https://sergiocaminitti.github.io/

Página estática em HTML e CSS, sem frameworks nem dependências, com tema claro e escuro e layout para celular.

## Estrutura
- `index.html`: página com projetos, tecnologias e formação
- `curriculo.pdf`: currículo para download

## Como ver localmente
Abra o `index.html` no navegador, ou rode `python3 -m http.server` na pasta e acesse http://localhost:8000.
